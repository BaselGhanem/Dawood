# Dawood ERP - Official Post-Init Build

نسخة تشغيل رسمية بعد إتمام التهيئة الأولى. خيار التهيئة وكلمات المرور الأولية محذوفة من الواجهة والكود.

## خطوات النشر

1. ارفع الملفات إلى Root الريبو على GitHub.
2. ارفع `firestore.rules` يدوياً من Firebase Console > Firestore Database > Rules > Publish.
3. تأكد من تفعيل Email/Password في Firebase Authentication.
4. تأكد من إضافة دومين GitHub Pages في Authorized domains.
5. افتح `login.html` وسجل الدخول بالحسابات التي تمت تهيئتها مسبقاً.

## التعديلات المنطقية المطبقة

- حذف خيار تهيئة أول تشغيل نهائياً.
- تعريف المستخدمين من صفحة إدارة النظام فقط حتى يتم إنشاء Authentication + Firestore profile + username alias معاً.
- دعم تسجيل الدخول باسم المستخدم لكل مستخدم جديد عبر `loginAliases`.
- منع صفحة الموظفين من إنشاء حسابات دخول ناقصة.
- ضبط التحويل الداخلي: خصم فوري من المرسل، موافقة/رفض من المستلم فقط، والإرجاع عند الرفض.
- ضبط تسليم النقد: خصم فوري كرصيد معلّق، تأكيد/رفض من المستلم فقط، والإرجاع عند الرفض.
- السلفة الذاتية تخصم من صندوق صاحب الحساب وتزيد رصيد السلف.
- ترحيل الراتب أصبح يخصم المصروف من صندوق صرف محدد، وليس من صندوق الموظف المستلم.
- إضافة كشف حساب عميل PDF من شاشة العملاء.
- تفعيل طباعة الفاتورة من شاشة الفواتير.
- تفعيل فلاتر ذكية في التقارير وسجل الحركات.
- تحديث Firestore Rules لحماية الدور والحالة والصلاحيات من تعديل المستخدم لنفسه.

## ملاحظة أمنية مهمة

النظام Frontend + Firebase فقط بدون Cloud Functions. لذلك تمت حماية الحقول الحساسة مثل `role`, `status`, `permissions` من تعديل المستخدم لنفسه. أما حركات الرصيد فتتم عبر الواجهة وتسجل في `systemLogs`. لأمان محاسبي أقوى 100% مستقبلاً، يجب نقل تعديلات الأرصدة إلى Cloud Functions أو Backend محمي.

## تحديث واجهة الاستخدام

تمت مراجعة واجهة النظام بعد التشغيل الرسمي، وتم اعتماد نسخة أكثر بساطة للمستخدمين غير التقنيين:

- تصميم متجاوب للموبايل والتابلت واللابتوب.
- تحويل الجداول على الموبايل إلى بطاقات واضحة بدلاً من صفوف أفقية طويلة.
- تحسين القوائم الجانبية وأزرار التصدير والبحث السريع.
- تحسين النوافذ المنبثقة، الفلاتر، النماذج، أزرار الإجراءات، وحالات البيانات.
- الحفاظ على كل المنطق المحاسبي والصلاحيات بدون تغيير وظيفي.
